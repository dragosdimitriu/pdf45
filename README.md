# pdf/45

**pdf/45** ("pdf over 45") - a small, free PDF **viewer** for Windows and Linux. No editing, no cloud,
no accounts — it opens PDFs, lets you read, search, follow the outline and
print them.

Licensed under the **GNU GPL v3 or later**. See `LICENSE`.

## Features

- Continuous or single-page view, fit-width / fit-page / custom zoom
- Page navigation (toolbar, keyboard, Go-to-page, back/forward history)
- Full-text search with a results list and next/previous (`Ctrl+F`, `F3`)
- Outline / bookmarks panel
- Printing (page range, print to file) via the system print dialog
- Password-protected documents
- Recent files, drag & drop, open from the command line (`pdf45 file.pdf`)
- Help → Credits lists every free-software component the viewer is built on

## How it is built

| Layer | Component |
|---|---|
| Language | Python 3.10+ |
| GUI toolkit | Qt 6 via PySide6 (`QtWidgets`, `QtPdfWidgets`, `QtPrintSupport`) |
| PDF engine | PDFium, embedded in Qt's `QtPdf` module |
| Executable | PyInstaller (one-folder bundle) |
| Windows installer | Inno Setup (`packaging/windows/pdf45.iss`) |
| Linux installer | `.deb` built with `dpkg-deb` (`packaging/linux/build_deb.sh`) |

Qt does the heavy lifting: `QPdfView` renders, `QPdfSearchModel` searches,
`QPdfBookmarkModel` exposes the outline. Printing rasterises each page at
printer resolution and paints it through `QPrinter` (`src/pdf45/printing.py`).

## Run from source

```bash
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
python -m pdf45 path/to/file.pdf
```

## Tests

Headless (no display needed):

```bash
QT_QPA_PLATFORM=offscreen pytest -v
```

`tests/fixtures/sample.pdf` is generated by `tests/make_fixture.py` (ReportLab).

## Build the installers

### Linux (.deb)

```bash
pip install -e ".[dev]"
pyinstaller --noconfirm packaging/pdf45.spec
packaging/linux/build_deb.sh            # -> dist/pdf45_<version>_amd64.deb
sudo apt install ./dist/pdf45_*.deb
```

Build on the oldest distribution you want to support (CI uses Ubuntu 22.04);
PyInstaller bundles cannot run on a glibc older than the build host's.

### Windows (setup.exe)

```powershell
pip install -e ".[dev]"
pyinstaller --noconfirm packaging\pdf45.spec
iscc /DAppVersion=0.1.0 packaging\windows\pdf45.iss   # -> dist\pdf45-0.1.0-setup.exe
```

Requires [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`iscc` on PATH).

### Continuous integration

`.github/workflows/build.yml` runs the tests on Ubuntu and Windows, builds
both installers, uploads them as workflow artifacts, and attaches them to a
GitHub Release when you push a tag such as `v0.1.0`.
